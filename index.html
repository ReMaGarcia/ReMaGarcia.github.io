Solid Theion

Plataforma web a medida con configurador técnico y panel de gestión para una fábrica.

Aplicación web para una fábrica de lavabos, encimeras, bañeras y platos de ducha en Solid Surface, que produce cada pieza a medida. El cliente define su pieza en un configurador con croquis técnico en tiempo real y la fábrica gestiona catálogo, pedidos y mensajes desde un panel propio.

Qué hice

Diseño y desarrollo completo: backend, base de datos, API, interfaz, configuradores, panel de administración, seguridad y despliegue.

Lo más destacado

  • Reglas de fabricación validadas en servidor y navegador con la misma geometría.
  • Croquis técnico en SVG generado en tiempo real y guardado con el pedido.
  • Panel con pedidos, mensajes, catálogo y configuración con historial de cambios.
  • Contraseñas cifradas, consultas preparadas, protección CSRF, roles en servidor y límite de intentos.
  • PHP 8
  • Vue 3
  • MySQL
  • API REST
  • Bootstrap 5
  • SVG
